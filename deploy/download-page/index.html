Before you start

What the server needs

A single Linux machine, physical or virtual, in your network. Nothing is installed on analysts' computers.

Operating system

Any recent 64-bit Linux distribution supported by Docker.

Ubuntu 22.04 / 24.04Debian 12RHEL 9Rocky Linux 9AlmaLinux 9

Hardware

MinimumRecommended
CPU4 cores8 cores
Memory8 GB16 GB
Disk40 GB100 GB

Docker

Docker Engine 24 or later with the Compose plugin. Step 1 below shows how to install it.

Network

Inbound HTTPS (443) from analysts and your SIEM. Outbound HTTPS only for the cloud AI and threat-intelligence services you choose.

Access

An account with sudo rights on the server, and an address (DNS name or fixed IP) your users will open.

Installation

Up and running in four steps

Run these commands on the server. Most installations take about ten minutes from start to first sign-in.

01

Install Docker

Skip this step if docker compose version already works on the server.


            

            

              

              
On Rocky Linux and AlmaLinux, use https://download.docker.com/linux/centos/docker-ce.repo as the repository.

Server without internet access? Download both files on any computer with the buttons above, then copy them to the server (for example with scp or a USB drive).

          

        

      


      

        

          
03

          

            
Run the installer

            
Enter the address your analysts will open. It can be a DNS name or the server's IP address, and must stay the same afterwards.

            

              
              

              
The command below updates as you type.

            

            

            
The installer checks the server, loads the application, generates unique passwords and a certificate, and creates the first administrator. At the end it prints the temporary administrator password and the SIEM connection token. They are shown only once, so note them.

          

        

      


      

        

          
04

          

            
Sign in and connect your tools

            
Open the address in a browser and sign in as admin with the temporary password. You will choose your own password right away. Then, from the menu:

            
    
              
  • IntegrationsConnect your SIEM and case-management system, with a built-in guide.
    • 
              
  • LLM SettingsChoose your AI provider, or a model running on your own hardware.
    • 
              
  • CTI ConfigurationAdd the keys of the threat-intelligence services you use.
    • 
              
  • Users ManagementCreate accounts for your SOC managers and analysts.
    • 
            

            
With the certificate generated by the installer, browsers show a warning until you install your own certificate (see the installation guide).

          

        

      

    

  






  

    

      Upgrading
      
New version? One command.

      
Download the new package as in step 2, then run the upgrade from it. A backup is taken first, and if the new version does not start correctly, the previous one is restored automatically.
