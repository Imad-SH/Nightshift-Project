Before you start

One Linux server. Nothing on analysts' computers.

Physical or virtual, in your data center or your cloud. Here is what it needs.

01

Operating system

A recent 64-bit Linux distribution.

Ubuntu 22.04 / 24.04Debian 12RHEL 9Rocky 9Alma 9
02

Hardware

MinimumRecommended
CPU4 cores8 cores
Memory8 GB16 GB
Disk40 GB100 GB
03

Docker

Docker Engine 24 or later with the Compose plugin. Step 01 below installs it.

04

Network

Inbound HTTPS (443) from analysts and your SIEM. Outbound HTTPS only for the cloud services you choose.

05

Access

An account with sudo rights, and a fixed address for the server: a DNS name or an IP.

06

Analysts

A modern browser. Nothing to install, from any computer on your network.

Installation

Up and running in four steps.

Run these commands on the server. Most installations take about ten minutes from start to first sign-in.

  1. 01Install Docker
  2. 02Download and verify
  3. 03Run the installer
  4. 04Sign in and connect
01

Install Docker

Skip this step if docker compose version already works on the server.

Terminal

          

          

            
Terminal

02

          
Download and verify the package

          
The checksum proves the package arrived complete and unmodified.

          
Terminal

          
Server without internet access? Download both files on any computer with the buttons above, then copy them to the server, for example with scp or a USB drive.

        


        

          
03

          
Run the installer

          
Enter the address your analysts will open: a DNS name or the server's IP. It must stay the same afterwards.

          

            
            
            
The command below updates as you type.

          

          
Terminal

          
The installer checks the server, loads the application, generates unique passwords and a certificate, and creates the first administrator. At the end it prints the temporary administrator password and the SIEM connection token. They are shown only once, so note them.

        


        

          
04

          
Sign in and connect your tools

          
Open the address in a browser and sign in as admin with the temporary password. You choose your own password right away. Then, from the menu:

          
    
            
  • IntegrationsConnect your SIEM and case management, with a built-in guide.
    • 
            
  • LLM SettingsChoose your AI provider, or a model on your own hardware.
    • 
            
  • CTI ConfigurationAdd the keys of the threat-intelligence services you use.
    • 
            
  • Users ManagementCreate accounts for your SOC managers and analysts.
    • 
          

          
With the certificate the installer generates, browsers show a warning until you install your own certificate (see the installation guide).

        

      

    

  


  

    

      

        Upgrading
        
New version? One command.

        
Download the new package as in step 02, then run the upgrade from it.

    •

    • 
          
  • Settings, accounts and alert history are kept.
